# Due Diligence — Logística Marítima del Caribe SAS

Dashboard interactivo de due diligence (NIT 900.561.893-1). Contiene información financiera y de negociación confidencial.

**Este repositorio debe permanecer PRIVADO.**

## Ver el dashboard
- Con GitHub Pages activo (requiere plan Pro/Team/Enterprise para repos privados): abre el link de Pages.
- Sin Pages: descarga `index.html` y ábrelo localmente en el navegador.

## Contenido
- `index.html` — dashboard interactivo (resumen, línea de tiempo, Asercol, venta de flota, capitalización de la deuda, proyecciones a 36 meses, valoración oculta).
